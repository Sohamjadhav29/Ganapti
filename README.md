# सत्यमेव युवा मित्र मंडळ — गणेशोत्सव २०२६

This folder is ready to publish on GitHub Pages.

## Files
- `index.html` — complete responsive animated Marathi brochure
- `ganesh-banner.png` — Ganesh festival artwork used on the opening screen

## GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html` and `ganesh-banner.png` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. GitHub will give you a Pages URL such as:
   `https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/`

## QR code
Once the Pages URL is live, use that exact URL for the QR code. The QR should point to the webpage, not to a local file.
